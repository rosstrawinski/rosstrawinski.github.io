## About

Portfolio site for Ross Trawinski, aerospace engineering student at the
University of Maryland. Built to showcase hands-on projects: an FPV drone
build and the UMD Over Terrain Vehicle (OTV), with the Terrapin Rockets
aerostructures project to be added.

## Structure

```
index.html   → Home page
fpv.html     → FPV Drone Build project page
otv.html     → UMD Over Terrain Vehicle project page
```

Each page is a single self-contained HTML file (styles, images, and video
embedded inline) — no build step, no dependencies. Pages link to each other
by relative filename, so the site works as-is on GitHub Pages or any static
host.

## Running locally

No build tools needed — just open `index.html` in a browser, or serve the
folder locally:

```
python3 -m http.server
```
